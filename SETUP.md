# Local setup

How to run FuturePath on your own computer. It takes about 10 minutes the first time.
You need Git, Python and a terminal. You do **not** need an API key to try it.

## 1. Install the tools

- **Python 3.10 or newer** (we use 3.14) from https://www.python.org/downloads/
  - Windows: tick **"Add python.exe to PATH"** in the installer. If typing `python` opens the Microsoft Store, use `py` instead of `python` in every command below.
- **Git** from https://git-scm.com/downloads

Check both:

```bash
python --version
git --version
```

## 2. Get the code

```bash
git clone https://github.com/Pixel-droid-16/futurepath.git
cd futurepath
```

Already cloned? Get the latest version with `git pull origin main`.

## 3. Create a virtual environment and install the packages

This keeps the project's packages separate from the rest of your computer.

**Windows (PowerShell):**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

If PowerShell says running scripts is disabled, run `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` once, then activate again.

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

You'll see `(.venv)` at the start of the prompt when it's active. Activate it again each time you open a new terminal.

## 4. Create your `.env` file

Copy the example file:

```bash
# Windows (PowerShell)
Copy-Item .env.example .env
# macOS / Linux
cp .env.example .env
```

Every value is optional:

| Setting | What it does | Without it |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | Claude reads CVs (including scanned PDFs) and tags news signals | Keyword matching is used instead |
| `ANTHROPIC_MODEL` | Which Claude model to use | Defaults to `claude-opus-5-5` |
| `SIGNALS_REFRESH_HOURS` | Hours between automatic signal refreshes while the server runs; `0` turns it off | Refreshes daily |
| `ADMIN_TOKEN` | Lets other machines press Refresh signals | Only your own computer can refresh |

Get an API key from https://console.anthropic.com/. **Never commit `.env` or paste a key into code or chat.** `.env` is already in `.gitignore`.

Using a key costs money: each CV upload, and each signal refresh (once a day while the server runs, see step 5). Set `SIGNALS_REFRESH_HOURS=0` if you don't want automatic refreshes.

## 5. Start the server

```bash
python -m uvicorn backend.app:app --reload --env-file .env
```

Leave this terminal open. `--reload` restarts the server when you save a Python file. `--env-file .env` loads your settings; without it the app still runs, with keyword matching.

Open:

- **App:** http://127.0.0.1:8000 (start at **Start** in the top bar)
- **AI Lab (CV extraction test):** http://127.0.0.1:8000/ai-lab
- **API documentation:** http://127.0.0.1:8000/docs

Stop the server with **Ctrl+C**.

On the first start the app creates `futurepath_demo.sqlite3`, your own local database. It holds the curated trend signals and the saved people you create. It is not shared with your teammates and is not committed. Delete it to start again from scratch, with the server stopped.

About a minute after the first start, the app pulls the live news and research feeds once, then once a day after that.

## 6. Try it

1. Go to **Start**. Upload a **fictional** CV (PDF), or fill in the form.
2. Check and approve the skills, optionally take the 18-question interest quiz, and see **Results**.
3. Choose a career and open its **pathway** to see checked courses.
4. Open **Signals** to see the sources behind the demand scores, and press **Refresh signals**.

Use fictional CVs only. There are no accounts, so anyone using your server sees the same saved people.

## Changing the code

| To change | Edit | Then |
| --- | --- | --- |
| Page layout or text | `frontend/mockup_source/pages/*.html` | Run `python scripts/build_frontend.py`, then refresh the browser |
| Page behaviour | `frontend/mockup_source/logic/*.js` | Run `python scripts/build_frontend.py`, then refresh the browser |
| API or scoring | `backend/` | Nothing: `--reload` restarts the server |
| Careers, skills, courses | `data/*.json` | Restart the server (Ctrl+C, then start again) |

Don't edit `frontend/index.html` directly. It is generated by `scripts/build_frontend.py`, and your changes will be overwritten.

Before you push, run the tests:

```bash
python -m pytest -q
```

## Troubleshooting

| Problem | Fix |
| --- | --- |
| `python` opens the Microsoft Store (Windows) | Use `py` instead of `python`, or reinstall Python with "Add to PATH" ticked |
| `No module named uvicorn` / `fastapi` | The virtual environment isn't active: activate it (step 3), then run the command again |
| `address already in use` / port 8000 busy | Another server is still running. Stop it with Ctrl+C in its terminal, or use another port: add `--port 8001` and open http://127.0.0.1:8001 |
| The page shows **Failed to fetch** | The server stopped, or the page is on a different port from the server. Check the terminal and the address bar |
| CV extraction only finds a few skills | No API key is loaded. Check `.env` has `ANTHROPIC_API_KEY=...` and that you started with `--env-file .env` |
| You changed `.env` but nothing happened | Restart the server; settings are read only at start-up |
| A page change doesn't show | Run `python scripts/build_frontend.py`, then hard-refresh the browser (Ctrl+Shift+R) |
| `scripts/verify_integrity.py` reports `runpod_worker/...` as CHANGED on Windows | Git converts line endings on Windows; this is expected and harmless |
